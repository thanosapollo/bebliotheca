#+TITLE: Bebliotheca

* About

Bebliotheca is a digital recreation of the Library of Constantinople.
We preserve the literary heritage of the Rhomaic civilisation.

Texts are stored as Org-mode files: plain text, readable without
special tooling, trivially version-controlled, and exportable to HTML,
PDF, or LaTeX from a single source.

The repository tracks only original curatorial work and build
tooling.  All imported content is drawn from open scholarly
repositories (git submodules in =sources/=) and regenerated by the
build pipeline.

Website: [[https://bebliotheca.thanosapollo.org]]

* Quick start

#+begin_src sh
make import           # populate content from source corpora
make all              # build the site
make web              # preview at localhost:8080
#+end_src

* Structure

#+begin_example
content/
  gr/          Greek texts (.org source files)
  en/          English translations
  la/          Latin texts
public/
  gr/          Exported HTML (generated)
  en/
  la/
  index.html   Library index page
  themes/      CSS/JS themes
scripts/       Import and conversion tools
sources/       External corpora (git submodules)
sources.org    Source documentation, import status, and future plans
tests/         Validation scripts
#+end_example

* Dependencies

- GNU Emacs with Org-mode
- Python 3
- GNU Make
- Git (for submodules)

See =manifests.scm= for the full Guix environment.
