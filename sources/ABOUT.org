#+TITLE: Bebliotheca Sources

* Overview

This directory holds external text corpora used to populate the library.
Source repositories are tracked as git submodules, pinned to the commit
we last imported from. The actual =.org= files they produce live in
=content/{gr,en,la}/= and are *not* tracked in git, they are regenerated
by the import pipeline.

* Perseus Digital Library

- Submodule :: =canonical-greekLit/= → [[https://github.com/PerseusDL/canonical-greekLit]]
- Converter :: =scripts/convert_perseus_xml_to_org.py=
- Import script :: =scripts/import_perseus.sh=
- Manifest :: =perseus-manifest.txt= (lists all auto-generated files)

** Commands

| Command              | What it does                                      |
|----------------------+---------------------------------------------------|
| =make import=        | Import content from all source submodules          |
| =make update=        | Update all submodules to latest and re-import      |
| =make clean-sources= | Remove all auto-generated =.org= files            |

** Manifest

=perseus-manifest.txt= is a plain list of file paths (one per line) for
every =.org= file produced by the import. It is tracked in git as a
provenance record.
