#+TITLE: Bebliotheca Sources

* Overview

External text corpora used to populate the library.  Source repos are
git submodules pinned to the commit we last imported from.  The =.org=
files they produce live in =content/{gr,en,la}/= and are tracked in
git.

#+BEGIN_QUOTE
Imports are additive: new files only, existing files are never
overwritten.
#+END_QUOTE

* Import Pipeline

| Command              | What it does                                  |
|----------------------+-----------------------------------------------|
| =make import=        | Import new files from all sources             |
| =make update=        | Update submodules to latest, then re-import   |
| =make clean-sources= | Remove all auto-generated =.org= files        |

Each source produces a manifest in =log/*-manifest.txt=. Import
filenames listed in =log/known-duplicates.txt= are skipped
automatically to avoid overwriting hand-curated works.

- Submodule :: =apostolic-fathers/= => [[https://github.com/jtauber/apostolic-fathers]]

- Manifest :: =log/apostolic-manifest.txt= (14 entries)

Late 1st to mid-2nd century Christian texts. Plain =chapter.verse=
format. Epistle of Barnabas excluded (already present from Perseus).

** Patrologia Graeca (Migne)

One-time conversion from PDFs; not reproducible from this repo.
1539 Greek works from 135 authors, covering 141 of 161 PG volumes.
The =.org= files in =content/gr/= are the authoritative copies.

- Directory :: =pg-migne/= (https://thanosapollo.org/pg-migne.tar.gz)
- Source :: University of the Aegean, /Paths of Faith -- Digital Patrology/ (2006)
- Languages :: Greek
- Status :: 1539 works, 1544 PDFs, 135 authors, 141 of 161 volumes

*** PG volume tags

Each PG file has =pgNN= or =pgNN-MM= tags in =#+FILETAGS:=. The
index page search is range-aware: =#pg50= matches =pg47-64=. Tags
are verified against =sources/pg-migne/volumes.org= using
=scripts/verify_pg_volumes.py=.

** Evaluated and rejected
- *TLG*: Subscription-only.
- *Digital Loeb*: Copyright-restricted.
- *Brepols*: Subscription-only.
- *Documenta Catholica Omnia*: =.doc= and =.pdf= files, impractical.
- *Open Patrologia Graeca*: Raw noisy OCR, major cleanup needed.
- *Scholarios PG Online*: Browse-only, not extractable.
