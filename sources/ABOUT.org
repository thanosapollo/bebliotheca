#+TITLE: Bebliotheca Sources

* Overview

This directory holds external text corpora used to populate the library.
Source repositories are tracked as git submodules, pinned to the commit
we last imported from. The actual =.org= files they produce live in
=content/{gr,en,la}/= and are *not* tracked in git, they are regenerated
by the import pipeline.

* Import Pipeline

All sources are imported by a single unified script:

| Command              | What it does                                  |
|----------------------+-----------------------------------------------|
| =make import=        | Import content from all source submodules     |
| =make update=        | Update all submodules to latest and re-import |
| =make clean-sources= | Remove all auto-generated =.org= files        |

Each source produces a *manifest file* (=*-manifest.txt=), a plain list
of file paths (one per line) for every =.org= file produced by the
import. Manifests are tracked in git as provenance records.

* Apostolic Fathers

- Submodule :: =apostolic-fathers/= => [[https://codeberg.org/bebliotheca/apostolic-fathers]]
- Converter :: =scripts/convert_apostolic_to_org.py=
- Manifest :: =apostolic-manifest.txt= (14 entries)
- Languages :: Greek

The Apostolic Fathers are the earliest Christian writers outside the New
Testament, dating from the late first to mid-second century. This
corpus includes the epistles of Clement of Rome, Ignatius of Antioch,
and Polycarp of Smyrna, the Didache, the Shepherd of Hermas, the
Martyrdom of Polycarp, and the Epistle to Diognetus.

The source texts use a plain =chapter.verse= format (one line per verse),
with the Shepherd of Hermas using a three-level =section.chapter.verse=
format. The Epistle of Barnabas is excluded from this import as it is
already present in the library from the Perseus Greek corpus.
